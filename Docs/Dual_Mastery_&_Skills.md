## 1. 原生毒株基底设计 (Base Mastery Foundation)

原体通过在探索探索中吞噬特定种族的怪群积累对应的"种族基因序列值"。当原体等级达到特定阈值时，可解锁并激活至多两种毒株专精进行深度缝合。

### 🧬 异变者专精 (Mutant Mastery)

* **核心定位**：物理撕裂、高最大生命值、生物反伤、动作电位爆发。
* **基础属性加成偏向**：每投入 1 点专精点，固定提供 `+5 HP_Max`，`+1.5 ATK`，`+0.5 DEF`。
* **专精特质**：解锁高倍率的物理伤害反弹，以及在 进程 饱满时触发的额外物理破甲效果。

### 🦟 寄生群落专精 (Swarm Mastery)

* **核心定位**：持续神经毒素、大面积气溶胶挂毒、百分比生命吸取。
* **基础属性加成偏向**：每投入 1 点专精点，固定提供 `+3 HP_Max`，`+2.0 ATK`（转化为毒素隐性伤害）。
* **专精特质**：使毒素自溶伤害可以无视怪物的防御护盾，并具备"传染"至相邻敌方单位的能力。

### 🤖 机械余烬专精 (Ember Mastery)

* **核心定位**：科技护盾、电荷过载偏转（概率免消耗）、进程 极速恢复。
* **基础属性加成偏向**：每投入 1 点专精点，固定提供 `+2 HP_Max`，`+1.0 DEF`，`+0.5 进程_Max`。
* **专精特质**：彻底改写能量流转，每回合开始时额外获得 进程 恢复加成，并在释放技能时概率发生电荷过载偏转。

## 3. 卡牌费用化与战斗手牌系统 (Card Economy & Hand System)

为了彻底根除原本自动对撞的无脑感，v2.0 彻底取消了基于 `setInterval` 的计时器自动 Tick 循环。战斗彻底交由**玩家逻辑/卡牌机制**驱动。

### 3.1 动作电位（进程）全面转为"行动费用"

* **回合恢复机制**：每局自动战斗删除。采用**暗黑式卡牌蓄能池**机制：

$$\text{本回合可用 进程} = \min\left(10,\ \text{上回合剩余 进程} + 3 \text{点（基础）} + \text{代谢腺体中心修正值} + \text{机械专精充能}\right)$$

  * **蓄能留存**：未消耗的 进程 自动留存至下一回合，上限锁死为 `player.ram_max = 10` 点。
  * **费用锁死**：玩家打出对应器官卡牌时，立刻扣除当前可用的 进程 点数。若 进程 不足，卡牌变暗，无法出牌。

### 3.2 装备常驻化手牌（Permanent Hand）

玩家装备的 3 个突变器官（捕食、表皮、代谢）以及配制的药剂，在进入探索副本房间时，直接转换为**常驻战斗卡牌**并排平铺于战场最下方：

```text
[ 卡牌 1：⚔️ 捕食攻击胞器 ] -> 对应装备的器官技能（如：毒素咬击，消耗 2 进程）
[ 卡牌 2：🛡️ 生物表皮层 ] -> 对应装备的防御技能（如：尖刺外凸，消耗 3 进程）
[ 卡牌 3：⚗️ 代谢腺体中心 ] -> 对应装备的连招核心（如：胃酸消化，消耗 3 进程）

```

## 4. 核心卡牌化学连招引擎 (Combo Matrix)

拒绝死板的代码堆砌。新 AI 在改写 `Combat.js` 的卡牌触发函数时，必须严格执行状态触发器（Status Trigger）的链式判定，以此支撑起极具爽感的 Theorycrafting：

### 🔄 连招多米诺判定流程

1. **基础卡施加标记**：玩家花 2 点 进程 打出卡牌 `剧毒口器`。扣除 2 点 进程，目标怪物被标记为 `m.status = 'poison'`。
2. **终结卡检测标记**：玩家接着花 3 点 进程 打出卡牌 `变异者活性胃袋`。
3. **连锁效益熔断**：
* **满足条件**：代码内部必须检测到目标 `m.status === 'poison'`。若满足，立刻将 `m.status` 强制抹除（重置为 `null`），并在同 1 个 Tick 内将伤害系数拉升至玩家基础攻击力的 **300% 爆破**！
* **超量回血转化**：该次爆破造成的最终伤害值，通过 `p.hp = Math.min(p.hp_max, p.hp + 最终伤害)`，100% 毫无损耗地反哺注入原体生命槽。
* **不满足条件**：若怪物未挂毒，胃袋仅能造成 50% 攻击力的极低酸蚀，不触发任何吸血。
