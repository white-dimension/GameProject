# 开发日志 (Development Log)

## V1.0 — 2026-06-14 🎉 Demo 完成

> **黑平线：原体觉醒** 首个可玩 Demo 版本

- 战败回母巢无路径：`_campHide` 双重过滤冲突，移除 `boss: true`

**UX 改进**

- 通关画面：打字机动效 + 统计行 + 绿色按钮，与开始界面风格统一

## v3.6 — 2026-06-14

### 地图系统重构 — 楼层制探索
- 从无限随机生成改为 **4层深度网络** (B1~B4)，每层 5~9 个预生成节点
- B1 母巢最小(4~5节点)→B4 最大(8~9节点)，渐进扩张
- Boss 初始隐藏，清除 ≥60% 楼层节点后现身；击败后解锁传送门推进
- 新增 **遗物节点**（非战斗奖励，随机给组件/BP/回血/清毒）
- 删除重新扫描和强制撤退（节点固定不需要刷新）

### Bug 修复 (v3.6.x)
- **战败后母巢无路径**：`_renderDiscovery` 的 `_campHide` 双重过滤把 `_genDiscoveryPaths` 兜底加回的 Boss 路径再次干掉，移除 `boss: true` 解决
- **中毒回合数不减少**：`_processStatusEffects` 只造成 DOT 伤害但从未 `mon.status['poison']--`，导致中毒永久持续
- **B4 通关传送门问题**：`FLOOR_CONFIG` 只有 B1~B3 定义，B4 回退到 B1；改为 B4 Boss 击败后显示通关画面
- **药水快捷键无效**：keydown 只映射 1/2/3→器官，漏了 4/5/6→魔药
- **专精重置丢失点数**：`learnMastery` 切换流派时未退还旧投入；加 `resetMastery` 函数全额退款

### UX 改进
- **路径卡片保留手牌**：营地/遗物点击后只消耗被点卡片，其余保留；全部用完后才刷新
- **战败后节点复活**：死亡返回母巢后随机复活 2~3 个非 Boss 节点，避免只剩 Boss 打不过
- **通关画面**：B4 Boss 击败后弹出全屏通关画面（等级/击杀/遗物统计 + 重新开始按钮）
- **流派切换**：已装备流派旁加「重置」按钮（全额退款）+「切换」其他种族选项

### 底部操作栏
- HUD 按钮(档案/存档/图鉴)移至底部信息条，顶部只留标题+状态条+?
- 底部显示楼层进度：`B2F  节点 3/7  ████░░  领主已现身`
- 四个按钮加图标：🧬实验室 📦档案 🐛图鉴 💾存档

### 完整颜色体系
- 19 个 CSS 变量统一控制所有颜色（5背景+6语义+3种族+4文字+1边框）
- JS/CSS 零硬编码色值，50+ 处替换为 CSS 变量
- 新增种族色：异变者红(#ff6b4a) 寄生群落绿(#9acd32) 机械余烬蓝(#4ab8ff)
- 路径卡片/房间名/战斗怪物卡片全部按种族着色
- 怪物意图弹窗按技能类型着色，战斗日志全面着色

### 41 个 SVG 图标 (emoji 全部替换)
- 35 个 Game-icons.net + 6 个 Lucide(MIT) = 41 个图标
- 所有 emoji 替换为 CSS mask-image SVG 图标
- 战斗状态标签/伤害浮动/玩家Buff全部用对应图标

### 组件系统增强
- 选择式合成：选 3 个组件 → 同种升级(Ⅰ→Ⅱ→Ⅲ，词条×2/×4/×8) / 不同随机
- 组件详情加掉落源(按种族着色)、可装备/涂层/合成说明

### 战斗 UI 增强
- 怪物状态标签独立卡片外(中毒/护盾/闪避/蓄力/狂怒/防御)
- 玩家 Buff/Debuff 战斗界面居中显示
- 战斗提示面板 悬停展开详细说明(技能+魔药)
- 怪物卡片选中用种族色光晕替代红色边框
- 魔药战斗快捷键 [4][5][6] + 提示面板说明

### 图鉴改进
- 按种族分类(异变者/寄生群落/机械余烬)，颜色标题
- 卡片种族色边框+名字
- 顶部信息栏显示总击杀数+种族克制说明

### 文字统一
- 货币：DNA→基因点数，RAM→进程，HP→生命，ATK→攻击，DEF→防御
- 所有缩写(HP/RAM/BP/TOX/XP/DOT)从教程和 UI 中移除

### 任务系统

## v2.1.6 — 2026-06-14

### 主界面布局重构

**左侧面板列重组**
- 传感器扫描、房间名称、房间描述从右侧 `_mainView` 移至左侧 `left-panel-col`，插入指令面板和日志面板之间
- `#ui-room-info` 使用 `position:absolute; top:50%; transform:translateY(-50%)` 垂直居中，不受日志面板增长影响
- 指令面板和日志面板 `max-width: 230px`（原 340px 缩小 1/3）

**固定间距布局**
- `left-panel-col` 改为 `flex:1`，吸收浏览器缩放产生的多余宽度
- 竖线 `#ui-divider`（1px, #1a2a3a）与指令/日志面板顶底对齐（margin: 25px 30px 25px 0）
- 卡片区 `_mainView` 固定 460px + `margin-right: 30px`
- 竖线→卡片 30px，卡片→屏幕右边缘 30px，全部固定不变

**加载动画联动重写**
- HUD 进度条与日志面板逐条联动：
  1. 神经链路已建立 → HP 条填充 → 生命已补充完成 → RAM 条填充 → 进程已补充完成
  2. 指令扫描中 → 指令面板动画 → 指令扫描完成
  3. 传感器扫描中 → 房间名称/描述打字 → 传感器扫描完成 → 当前位置已锚定
  4. 路径卡片弹出
- 新增模块级 `_pushLog()` 辅助函数，`_renderTasks` 和 `_renderDiscovery` 完成时自动插入联动日志
- 已有存档跳过全部动画，直接静态渲染

**路径卡片规范**
- 图标改为 `display: inline-flex; align-items: center`，与文字垂直居中对齐
- 卡片标题 `display: flex; align-items: center; gap: 6px`
- 字号统一遵循设计规范：标签 xs(13px)、标题 sm(14px)、描述 xs(13px)
- 卡片内边距：`22px 30px 20px 30px`，文字 `text-align: left`
- 容器 `max-width: 400px`，在 `_mainView` 内 `justify-content: center` 居中
