# 03 — 神经触突探索网络与地下城架构

> **v3.10 更新 (2026-06-18)**: 将楼层扩展至 B10F，正式实装“超越进化”二周目继承机制及局内突发事件。

## 0. 楼层制探索 (核心架构)

实验室目前已开放共 **10 层 (B1-B10)**，每层节点规模随深度线性增长。

| 层级 | 节点规模 | 核心特征 | 典型领主 |
|---|---|---|---|
| **B1 (源初区)** | 4~5 | 教学引导区，固定母巢起点 | 暴君 |
| **B2-B3 (扩散区)** | 6~7 | 引入地下城入口与精英变异体 | 蜂后 / 核心 |
| **B4-B9 (深层区)** | 8~10 | 高频率遭遇游荡 Boss 与环境异变 | 随机领主 |
| **B10 (终局区)** | 12 | 最终决战，击败领主后触发通关 | 领主连战 |

### 0.1 超越进化 (Loop+) 二周目机制

通关 B10F 击败最终领主后，原体可选择进入“超越进化”循环：
*   **完美继承**：保留所有基础属性（含基因突变）、背包物资、**器官同调等级**及**图鉴研究进度**。
*   **难度阶梯**：每一轮新循环 (Loop 2, 3...)，怪物的生命值与攻击力基础倍率永久提升 **30%**。
*   **资源膨胀**：基因点数 (BP) 收益随循环次数同步小幅上扬。

## 1. 动态神经触突路径系统 (Neural Synapse Discovery)

大世界由原体感知到的“神经触突”分支构成。

### 1.1 分支探索逻辑

*   **路径抉择**：在每个节点侦测到 2-3 条前进路径。
*   **状态继承**：生命值（`player.hp`）、进程（`player.process`）和毒性值（`player.toxicity`）持续流动。

### 1.2 步进移动触发器

当原体选择路径并深入时，系统顺序执行：
1.  **感官异常判定 (v3.10)**：有 **25% 概率触发【局内突发事件】**（详见第 4 节）。
2.  **毒性压制判定**：若毒性 > 50，扣除 2% 最大 HP。
3.  **环境切入**：进入战斗、营地或触发奖励。

## 2. 核心节点类型 (Core Node Types)

| 节点类型 | 视觉符号 | 战术价值 |
| --- | --- | --- |
| **中立细胞核** | camp | HP/进程回满、毒性清零。 |
| **怪物巢穴** | monster | 战斗节点，获取 BP 与组件碎片。 |
| **强敌据点** | elite | 精英怪驻守，稳定产出高阶碎片。 |
| **基因遗物** | relic | 随机奖励（属性加成、稀有器官、大量 BP）。 |
| **地下城** | dungeon | 多层连续挑战，终点固定产出领主宝箱。 |
| **传送门** | portal | 推进楼层至更深层级。 |

## 3. 地下城副本层级推进深度 (Dungeon)

### 3.1 副本准入环境预警
玩家点击地下城卡片后，UI 会强制弹出**环境代码变异**预警。

### 3.2 深入机制
在地下城战斗胜利后，可使用快捷键 **[0]** 快速“深入地下城”至下一层，直至最终层击败领主。

---

## 4. 局内随机突发事件 (Random Events) - v3.10 核心

系统在路径跳转间植入的“突发状况”，要求玩家在利益与代价间做出即时决策。

### 4.1 触发规则
*   **激活条件**：非 B1F 起点、非 Boss 房、非传送门节点。
*   **典型事件**：【非法炼金商】（购买/掠夺）、【能量网路过载】（提升进程上限）、【前代残骸】（获取 XP/碎片）、【寄生群落】（群体中毒）、【金属货柜】（BP/组件抽奖）。
*   **逻辑闭环**：事件处理完毕后，原有的路径探索逻辑将继续执行，确保进度不丢失。
