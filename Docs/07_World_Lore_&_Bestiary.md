## 1. 黑地平线变异体图鉴 (Bestiary)

原体对实验室生物的了解随击杀数与**深度研究**而加深。

### 1.1 基因深度研究系统 (Research Rank)
玩家可消耗基因点数 (BP) 解锁针对特定变异体的研究等级：

*   **Lv.1【解构】**：战斗中显示该怪物的 **精确剩余 HP / 最大 HP**。
*   **Lv.2【弱点】**：对该怪物的 **所有伤害永久提升 10%**。
*   **Lv.3【收割】**：击败该怪物时，**组件碎片掉落率提升 25%**。

## 2. 三大生态群落特质

| 群落名称 | 核心特质 | 典型弱点 |
| --- | --- | --- |
| **异变者 (Mutant)** | 极高生命、物理反伤 | 惧怕【寄生】毒素的百分比侵蚀。 |
| **寄生群落 (Swarm)** | 快速闪避、毒素传染 | 惧怕【机械】类的高压电离与真实伤害。 |
| **机械余烬 (Ember)** | 科技护盾、进程干扰 | 惧怕【异变】类的纯物理撕裂与破甲。 |

## 3. 世界级首领 (World Bosses)

### 3.1 暴君级变异体 (MON_CH1_TYRANT)
*   **特质**：外骨骼坚硬无比。
*   **同调产出**：暴君核心（Lv.3 觉醒后可造成无视防御的真伤）。

### 3.2 畸变蜂后 (MON_CH1_QUEEN)
*   **特质**：高频产卵孵化，产卵期间 100% 闪避但防御归零。
*   **攻略**：必须在产卵预兆出现时使用【腺体脉冲】进行连招爆破。

### 3.3 安保系统核心 (MON_CH1_CORE)
*   **特质**：每回合刷新 200 点科技护盾，对物理打击抗性极高。
*   **同调产出**：高能电泳核（Lv.3 觉醒后提供全场连锁溅射）。
