## 1. 三大生物部位插槽刚性宪法 (Three Mutation Slots Constitution)

原体拥有 3 个与 DNA 链直接相连的常驻生物部位插槽。下一任接盘 AI 在重构 `UI.js` 与 `Combat.js` 的装配校验逻辑时，必须死守以下**刚性类型强限制，绝对禁止跨槽任意覆盖安装**：

### 1.1 ⚔️ 捕食攻击胞器 (`predatory_organ`)

* **装备限制**：仅允许装备 `type: 'attack'`（攻击类）器官（如：高频震动触手、剧毒口器）。
* **核心职责**：决定原体的基础物理伤害，并作为手牌系统中的"主动攻击牌"提供主动技能 1。

### 1.2 🛡️ 生物表皮层 (`chitin_epidermis`)

* **装备限制**：仅允许装备 `type: 'defense'`（防御类）器官（如：外骨骼骨板、生物反伤刺甲）。
* **核心职责**：决定原体的固定伤害减免系数与被动反伤百分比，作为手牌系统中的"御体防卫牌"。

### 1.3 ⚗️ 代谢腺体中心 (`gland_core`)

* **装备限制**：仅允许装备 `type: 'gland'`（腺体类）器官（如：变异者活性胃袋、电泳能量核）。
* **核心职责**：决定原体在卡牌回合制中每回合可用动作电位（RAM）的恢复速度上限，并作为"连招/流派终结牌"。

## 2. 恐怖黎明式：基因碎片镶嵌机制 (Component Slotting System)

所有从开放世界大世界中吞噬怪物剥离出来的材料（如：`纳米破片`、`毒囊材料`等），**绝对不可直接出售，也严禁直接点击扣除来线性增加玩家属性**。所有材料全面转为【常驻基因镶嵌物（Components）】。

### 2.1 镶嵌规则

* 每个生物器官插槽天然具备 **2 个碎片镶嵌孔（Component Slots）**。
* 玩家必须在【源初母巢】安全区内打开重组台进行碎片活化镶嵌。
* 镶嵌后的碎片可以随时通过消耗 BP金币进行"基因完整剥离"或"摧毁器官保留碎片"。

#### 2.1.1 BP 生物经济体 (Bio-Points Economy)

* **资产代号**：`gameState.player.bp`（Bio-Points，生物体液点数）。
* **产出获取**：
  * 每消灭一只常规怪物，固定暴落 `2~5 BP`。
  * 每消灭一只精英怪，固定暴落 `15~20 BP`。
  * 成功击杀世界巡逻首领（Boss），固定赏赐 `100 BP`。
* **刚性消耗**：
  * 在母巢基因重组台剥离已镶嵌的 Component 碎片：单次操作强制扣除 `10 BP`（BP 不足则剥离置灰）。
  * 大后期在母巢重置双毒株专精洗点：单次扣除 `50 BP`。

### 2.2 核心 Component 基因碎片数据库映射

| 碎片名称 | 允许镶嵌插槽 | 单枚碎片提供的硬核属性词条 (Component Affixes) |

## 3. 非线性"数值刹车"与进化控制公式 (Numerical Brake Formulas)

为了确保游戏在无缝大世界中探索 10+ 小时内数值绝对不发生通胀崩溃，器官的阶位进阶（从 T1 升级至 T2、T3）以及碎片的叠层活化，必须严格执行**非线性指数增长公式**。

### 3.1 器官阶位进阶消耗公式

当玩家消耗同类高阶材料对器官进行突变阶位进阶时，升级所需的 Component 数量消耗公式锁死为：

$$\text{RequiredMaterials} = \text{BaseCost} \times 1.6^{\text{CurrentTier}}$$

* *T1 $\rightarrow$ T2 进阶*：$\text{BaseCost}(5) \times 1.6^1 = 8$ 个 Component 碎片。
* *T2 $\rightarrow$ T3 进阶*：$\text{BaseCost}(5) \times 1.6^2 = 13$ 个 Component 碎片。
* *T3 $\rightarrow$ T4 进阶*：$\text{BaseCost}(5) \times 1.6^3 = 21$ 个 Component 碎片。

### 3.2 属性收益递减（战力刹车）

为了严防玩家通过极致堆叠单一属性直接跨级秒杀大世界巡逻首领（如暴君），防御器官的伤害减免系数（`p.def`）必须引入暗黑式的**渐进饱和趋向公式**：

$$\text{ActualDamageReduction} = \frac{\text{p.def}}{\text{p.def} + 40}$$

* 当 `p.def = 10` 时，实际减免比例为：$\frac{10}{50} = 20\%$。
* 当 `p.def = 40` 时，实际减免比例为：$\frac{40}{80} = 50\%$。
* 当 `p.def = 120` 时，实际减免比例为：$\frac{120}{160} = 75\%$。

**设计目的**：任凭玩家在后期如何疯狂镶嵌高压电缆碎片，其实际伤害减免的生死线都会被死死卡在 $75\%$ 左右，逼着玩家去研究流派连招、吃药和涂抹基因油，而不是无脑靠肉身硬抗超级怪物的狂暴攻击。

### 3.3 取整铁律 (Rounding Constitution)

所有非整数的材料消耗、专精强化加成、以及非线性的伤害减免计算，在 JavaScript 代码执行层面**强制统一应用 `Math.ceil()` 向上取整函数**，以确保离线数据库的字符整数一致性。

## 4. 组件合成系统 (v3.6)

实验室组件库存区提供 `合成 3→1` 按钮，弹窗选择 3 个组件：

- **3 个相同** → 生成升级版（罗马数字命名：Ⅰ→Ⅱ→Ⅲ），词条数值倍增（×2→×4→×8）
- **3 个不同** → 随机获得 1 个新组件

升级版组件动态创建在 `GD().COMPONENTS` 中，与原版共享 `allowedSlots`。每级合成消耗 3 个同款，逐级攀升。

组件详情悬停提示包含：词条、可装备插槽、可用于涂抹、合成说明(3个相同→Ⅰ级升级)、掉落源(按种族着色)。
