- **回合计数双倍**: 删除 `_finishMonsterTurn` 中重复的 `turn++`，狂怒/小怪生成间隔恢复正确时序。
- **怪物数据缺失**: `_monsterAction` 增加 `GD().MONSTERS[id]` 空值防护，未知怪物自动跳过。
- **器官阶位 NaN**: `recalcPlayerStats` 中 `slot.tier` 增加 `|| 1` 兜底，防残缺存档永久坏档。
- **导入跳过迁移**: `importSaveText` 增加 `_migrateOldSave` 调用，旧版粘贴存档不再散花报错。
- **随机事件空值**: `World.js` 增加 `GameData.RANDOM_EVENTS` 存在性判断，Data.js 未加载时静默跳过。
- **组件空库写垃圾**: 组件库为空时不发组件奖励，防止 `inventory.components["undefined"]` 污染。
- **逃跑操作锁**: 逃跑成功后立即锁定 `_fleeing` 标记，400ms 窗口期禁止额外操作。
- **scan 意图死亡**: 扫描意图增加 `p.hp <= 0` 检查，避免重复 `_doDefeat`。
- **reset 内存清理**: `GameState.reset()` 同步置空 `window._activeGameState`，防旧存档被偷偷写回。
- **电离标记真两步**: ember 种族首次命中施加标记、下次命中才引爆，不再同一击内自标记自引爆。
- **exitBattle 空值**: 增加 `gs` 空值检查，极端场景不崩。
- **节点耗尽兜底**: `_poolIndex` 为空时通过 `target.id` 在池中反向匹配，节点计数百分比准确。
- **探索入口 null 检查**: `World.discover()` 增加 `gs.player` 空值检查。

**双专精系统补全**
- **同系 150% 叠加**: A+A+B 配置时，重复种族的 `masteryPoints` 乘 1.5 倍计算属性加成。
- **三插槽被动优先级**: 当三槽各异（A+B+C），按 mutant > swarm > ember 优先级选取双专精被动组合。
- **终焉母核闪避清除**: ember+ember 每回合连锁闪电前清除所有怪物的 `dodging` 状态。

**盾核魔药副作用实现**
- POT_SHIELD_CORE 使用后附加 `_toxResistDebuff`，毒性 > 50 时自溶伤害从 2% 升至 2.4%。

**新增 3 种魔药**
- POT_HEAL（凝血再生剂，回血 40%，防御下降 3 回合）
- POT_DEFENSE（角质硬化素，防御 +50%，攻击下降 3 回合）
- POT_RAM（神经突触催化剂，回复 5 进程，额外 +10 毒性）
- 实验室炼制面板和炼金商抢劫事件均已开放全部 6 种魔药。

**高阶组件碎片加权**
- 进阶消耗按品质加权：基础碎片 = 1，Ⅰ = 2，Ⅱ = 3，Ⅲ = 4。消耗时优先扣高品质。

**训练场**
- 实验室新增"训练场"按钮，进入战斗面对 3 个种族训练人偶（HP 9999、不还手）。
- 可自由测试技能/涂层/魔药/种族克制效果，按 Q 退出，不消耗资源、不影响进度。

**文档同步更新**
- Alchemy_&_Preparation.md: 数值全面对齐代码（突变成本、涂层消耗、魔药毒性、护盾值等），补全 3 种新魔药。
